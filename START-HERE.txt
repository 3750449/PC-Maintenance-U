PC MAINTENANCE - START HERE

NORMAL USE
1. Extract this whole folder from the ZIP.
2. Open the folder.
3. Double-click Run-PC-Maintenance.bat.
4. Approve the Windows administrator prompt.
5. Pick an option from the menu.

NO INSTALLER IS REQUIRED.
NO GIT INSTALLATION IS REQUIRED.

Keep these files together in the same folder:
- PC-Maintenance.ps1
- Run-PC-Maintenance.bat
- Update-PC-Maintenance.ps1
- version.txt

UPDATES
Choose option 4 inside PC Maintenance.
The program checks:
https://github.com/3750449/PC-Maintenance-U

For one-click family updates, that GitHub repository must be public.

GITHUB REPOSITORY SETUP
Upload the files from this folder to the ROOT of the main branch of:
https://github.com/3750449/PC-Maintenance-U

Required repository-root files:
PC-Maintenance.ps1
Run-PC-Maintenance.bat
Update-PC-Maintenance.ps1
version.txt

When publishing a future update:
1. Change $AppVersion near the top of PC-Maintenance.ps1.
2. Change version.txt to the same version number.
3. Upload/commit the changed files to the main branch.
4. Users choose option 4 to update.
