PROJECT / CODE SEARCH

Designed to locate old programming projects even when you do not remember the
exact folder. It can search using:
- Project, folder, or source filename clues
- Old path/folder-origin clues
- Programming language / code type
- Libraries, imports, includes, class names, function names, algorithms,
  comments, README terms, or purpose keywords
- Project markers such as .git, CMakeLists.txt, package.json, requirements.txt,
  pyproject.toml, Cargo.toml, pom.xml, build.gradle, Makefile, Dockerfile, etc.

Matches are grouped into likely project roots, ranked, and exported to CSV.
The search can open a selected project folder directly in Explorer.

The purpose search is keyword/content based. It can find concepts described in
README files, comments, names, imports, and code, but it is not an AI semantic
index of every project.

WSL / LINUX TERMINAL MAINTENANCE

The Linux menu can:
- Show WSL status and installed distributions
- Check Linux package updates
- Update a selected Linux distribution
- Update the Windows WSL engine/kernel
- Open a selected WSL distribution terminal

Supported package managers:
apt, dnf, yum, pacman, zypper

A Linux sudo password may be requested by the distribution during updates.

SPEECH LISTENER / MICROPHONE

The Speech Listener can:
- List built-in and attached Windows audio endpoints
- Listen for 15, 30, or 60 seconds through the current default Windows input
- Save recognized speech and confidence values to a CSV report
- Open Windows Sound settings so a USB/Bluetooth headset or external mic can be
  made the default recording device

The listener is opt-in. It does not secretly stay running or continuously
record in the background after the listening session ends.

FILE CONVERSION

The converter is engine-based. Built-in Windows support handles common images,
CSV/JSON, text-like files, and Office-to-PDF when Microsoft Office is installed.
Publisher rescue includes .pub discovery/conversion support.

Optional engines detected automatically include FFmpeg, ImageMagick,
LibreOffice, Pandoc, and 7-Zip.

DEEP FILE SEARCH / LOST FILE FINDER

Supports partial filenames, wildcards, fuzzy filename ranking, old path clues,
extensions, size/date filters, all-drive searches, hidden files, Publisher .pub
search, CSV result reports, and Explorer reveal.

DRIVE PHOTO SEARCH / DESKTOP BACKUP

Use menu option 10 to search for photos on internal drives, USB drives,
external storage, accessible network drives, or a selected folder.

The program can make a dated backup on the current Windows user's Desktop.

Example:
Desktop\Photo-Backup-2026-11-08_09-30-00

The backup COPIES files. It does not move or delete the originals.
A CSV manifest is created inside the backup folder.


EXTERNAL DRIVE HEALTH / DIAGNOSIS

Use menu option 11 for an external HDD, SSD, USB flash drive, or storage
connected through a USB enclosure/adapter.

The default diagnosis is read-only. It does not initialize, format, erase,
or automatically repair the drive.

It checks whether Windows sees the disk, partitions, filesystem, health state,
and SMART/reliability information when the enclosure exposes it.

If Windows asks to FORMAT a drive containing important data, choose Cancel
until you know what filesystem and failure state the drive has.


APPLE / MAC EXTERNAL DRIVE READER & RESCUE

Use menu option 12 for an external drive that was formatted or used on a Mac.

It can detect known APFS/HFS+ partition types, diagnose the external-drive
hardware, open readable external volumes, search accessible files/photos/code,
and make a copy-only Desktop backup of a readable external volume.

If Windows asks to FORMAT the Mac drive and its data matters, choose Cancel.

PC Maintenance does not bundle proprietary APFS/HFS Windows drivers. If Windows
detects the Apple partition but does not mount it, use a compatible reader or
connect the drive to a Mac first.

MALWARE SWEEP

Defender scans automatically attempt to update Microsoft security intelligence
before scanning. The Security menu includes Quick, Full, Custom-folder, and
Offline Defender scans plus an optional fresh Microsoft Safety Scanner download.

No antivirus can guarantee detection of every new or zero-day threat.
